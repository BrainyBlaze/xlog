1//! Stream-ordered device memory runtime.
2//!
3//! [`crate::CudaProviderBuilder`] constructs one [`XlogDeviceRuntime`] and one
4//! [`crate::GpuMemoryManager`] that share the provider's exact CUDA device.
5//! The runtime owns the stream pool and composes the production resource stack:
6//!
7//! ```text
8//! XlogDeviceRuntime
9//!   -> StreamPool of non-blocking streams
10//!   -> LoggingResource (optional)
11//!   -> GlobalDeviceBudget
12//!   -> AsyncCudaResource
13//! ```
14//!
15//! [`GlobalDeviceBudget`] is the sole byte-admission authority. Optional
16//! [`LoggingResource`] wraps it so successful operations and typed admission
17//! failures are both observable exactly once. [`DirectCudaResource`] remains
18//! available for crate tests that need a synchronous allocator; canonical
19//! providers always use [`AsyncCudaResource`].
20//!
21//! Stream-ordered contract: every alloc / dealloc names a stream;
22//! reuse across streams requires explicit event/sync. No reliance on
23//! the CUDA null/default stream.

Expand description

Initial canonical parent only. A model continuation cannot be supplied here: it is admitted after a real Acquire and a forward using that acquired parent. PrefixIdentity is native-owned: fresh publication derives its 32 bytes from the actual PrefixSource. Supplying a caller record for that role is an error.

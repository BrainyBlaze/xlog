Struct ConditionalCudaGraphSequenceBuilder

pub struct ConditionalCudaGraphSequenceBuilder { /* private fields */ }
Expand description

Builds one dependency-ordered parent graph containing ordinary captured segments and any number of conditional-WHILE nodes.

This is the topology required by stratified Datalog: work before a recursive strongly connected component executes once, only that component is placed in a device-controlled WHILE, and later strata depend on its completion. The finished value still launches through one cuGraphLaunch.

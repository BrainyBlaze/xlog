Struct DirectCudaResource 

Source 
pub struct DirectCudaResource { /* private fields */ }
Expand description

Default-device-stream allocation adaptor. The live map retains actual raw owners while callers hold opaque DeviceBlock identities. Deallocation removes an exact identity and queues its actual owner after unlocking the map. Reclamation waits for shared leases; an unknown physical-free outcome retains the owner and its outstanding byte charge for a later reap.

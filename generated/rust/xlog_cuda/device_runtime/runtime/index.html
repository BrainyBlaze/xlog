xlog_cuda::device_runtime

Module runtime 

Source
Expand description

XlogDeviceRuntime hosts one provider-owned CUDA device, stream pool, and decorated memory-resource stack.

The canonical provider builder constructs the complete ownership graph and shares its exact handles with the memory manager. There is no process-global runtime registry: dropping a provider releases its runtime normally, and independently built providers never share allocator state accidentally.

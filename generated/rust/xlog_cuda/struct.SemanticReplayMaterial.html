Struct SemanticReplayMaterial 

Source 
pub struct SemanticReplayMaterial { /* private fields */ }
Expand description

Owned cold replay inputs: complete predecessor material and the successor’s external native publication evidence. Hash consistency does not establish historical execution, current rights, or permission to use a model.
